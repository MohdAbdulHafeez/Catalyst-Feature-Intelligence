# Contributing to CATALYST

## Development workflow

1. Create a focused branch.
2. Make one coherent change.
3. Add or update tests.
4. Run formatting, linting and tests.
5. Use a Conventional Commit message.
6. Open a pull request with a concise technical description.

## Commit format

```text
feat: add categorical cardinality profiler
fix: handle empty categorical columns
test: cover unseen category diagnostics
refactor: isolate encoder adapter interface
docs: document leakage prevention
perf: reduce benchmark transformation overhead
ci: add Python test matrix
```

Commits should represent real engineering work. Do not create artificial
commits solely to increase contribution activity.
